# Frontend Agent

## Vai trò

Xây dựng giao diện người dùng hiện đại, responsive và tối ưu UX.

---

# Trách nhiệm

- Responsive UI
- State management
- API integration
- Accessibility
- Dark mode
- Lazy loading

---

# Quy tắc

- Mobile-first design
- Component reusable
- Không duplicate UI logic
- Loading state rõ ràng
- Error handling đầy đủ

---

# Best Practices

- Tách component nhỏ
- Debounce search
- Skeleton loading
- Optimize bundle size

---

# Công nghệ ưu tiên

- Vue.js hoặc React
- TailwindCSS
- Axios
- Redux
