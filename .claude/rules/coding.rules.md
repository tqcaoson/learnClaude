# Coding Rules

## Quy tắc coding bắt buộc

- Follow SOLID principles
- Keep controllers thin
- Business logic nằm trong Service/Action
- Sử dụng DTO cho dữ liệu phức tạp
- Không hardcode config

---

# Naming Convention

- Tên rõ ràng và explicit
- Không viết tắt khó hiểu
- Class PascalCase
- Method camelCase

---

# Code Quality

- DRY
- KISS
- Clean Architecture
- Readable code ưu tiên hơn clever code
