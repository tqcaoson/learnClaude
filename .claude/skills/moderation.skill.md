# Moderation Skill

## Mục tiêu

Hỗ trợ kiểm duyệt nội dung cộng đồng.

---

# Chức năng

- Report content
- Hide/Delete content
- Lock discussion
- Warning user
- Content approval workflow

---

# Quy tắc

- Moderator chỉ quản lý board được assign
- Admin có quyền toàn hệ thống
- Ghi log moderation actions

---

# Best Practices

- Audit log đầy đủ
- Soft delete trước
- Có cơ chế restore
