# Security Skill

## Mục tiêu

Đảm bảo an toàn hệ thống.

---

# Các protection bắt buộc

- SQL Injection protection
- XSS protection
- CSRF protection
- Rate limiting
- Secure authentication

---

# Upload Security

- Validate MIME type
- Chặn executable file
- Giới hạn dung lượng
- Virus scanning nếu có thể

---

# Best Practices

- Principle of least privilege
- Escape output
- Không trust client input
- Audit log security events
