# 6. Thiết kế API

## 6.1 POST /api/auth/login

### Mô tả

API xác thực email/password.

---

### Request Header

```http
Content-Type: application/json
Accept: application/json
X-CSRF-TOKEN: {token}
```

---

### Request Body

```json
{
  "email": "user@example.com",
  "password": "secret123",
  "remember_me": true
}
```

---

### Validation Rules

| Field       | Rule                   |
| ----------- | ---------------------- |
| email       | required,email,max:255 |
| password    | required,min:8,max:255 |
| remember_me | nullable,boolean       |

---

### Success Response

```json
{
  "success": true,
  "message": "Login success",
  "data": {
    "user": {
      "id": 1,
      "name": "John Doe",
      "email": "user@example.com",
      "role": "member"
    },
    "token": "jwt_or_session_token"
  }
}
```

---

### Error Response

#### Invalid credentials

```json
{
  "success": false,
  "error_code": "AUTH_001",
  "message": "Invalid credentials"
}
```

#### Account locked

```json
{
  "success": false,
  "error_code": "AUTH_002",
  "message": "Account locked"
}
```

#### Email not verified

```json
{
  "success": false,
  "error_code": "AUTH_003",
  "message": "Email not verified"
}
```

---

## 6.2 POST /api/auth/logout

### Mô tả

Logout user và invalidate session/token.

---

### Success Response

```json
{
  "success": true,
  "message": "Logout success"
}
```

## 6.4 GET /api/auth/oauth/{provider}/callback

# 7. Sequence Design

## 7.1 Login Email/Password

```text
User
  ↓
LoginController@login
  ↓
LoginRequest validate
  ↓
LoginAction
  ↓
AuthenticationService
  ↓
LoginAttemptService check lock
  ↓
UserRepository findByEmail
  ↓
Verify password hash
  ↓
Check account status
  ↓
Check email verified
  ↓
Check 2FA enabled
  ↓
SessionService create session
  ↓
Regenerate session ID
  ↓
Dispatch LoginSuccessEvent
  ↓
Return response
```

---

## 7.2 Login Failed Flow

```text
Authentication failed
  ↓
Increase login attempts
  ↓
Store audit log
  ↓
Check threshold
  ↓
Temporary lock account/IP
  ↓
Return AUTH_001
```

---

## 7.3 OAuth Login Flow

```text
Guest
  ↓
OAuthController redirect
  ↓
Google/Facebook
  ↓
OAuth callback
  ↓
OAuthService validate provider token
  ↓
Find existing user
  ↓
Create new user if not exists
  ↓
Create session
  ↓
Dispatch LoginSuccessEvent
  ↓
Redirect homepage
```

# 8. Chi tiết xử lý nghiệp vụ

## 8.1 Validation Logic

### Email Validation

- Bắt buộc nhập
- Đúng format email RFC
- Trim khoảng trắng đầu/cuối
- Convert lowercase trước query DB

### Password Validation

- Bắt buộc nhập
- Min length: 8
- Không log raw password

---

## 8.2 Authentication Logic

### Step 1 — Kiểm tra login attempts

Điều kiện khóa:

| Rule          | Giá trị |
| ------------- | ------- |
| Max attempts  | 5       |
| Lock duration | 15 phút |

Nếu đang bị khóa:

- Trả AUTH_002
- Không thực hiện query password hash

---

### Step 2 — Tìm user

Query:

```sql
SELECT *
FROM users
WHERE email = ?
LIMIT 1;
```

Nếu không tồn tại:

- Tăng login_attempt
- Log failed login
- Trả AUTH_001

---

### Step 3 — Verify password

Sử dụng:

```php
Hash::check($password, $user->password)
```

Thuật toán:

- bcrypt
  hoặc
- argon2id

---

### Step 4 — Check user status

Các trạng thái:

| Status   | Cho phép login |
| -------- | -------------- |
| active   | Yes            |
| disabled | No             |
| banned   | No             |

Nếu disabled/banned:

- Trả AUTH_006

---

### Step 5 — Check email verification

Nếu policy verify email được bật:

```php
if (!$user->hasVerifiedEmail())
```

→ Trả AUTH_003

---

### Step 6 — Check 2FA

Nếu bật 2FA:

- Tạo temporary challenge session
- Chưa tạo authenticated session
- Redirect verify OTP screen

---

### Step 7 — Create authenticated session

Session handling:

```php
Auth::login($user, $rememberMe);
$request->session()->regenerate();
```

Sau khi login:

- Reset login attempts
- Update last_login_at
- Store user session
- Dispatch login success event

# 11. Security Design

## 11.1 Password Security

- bcrypt hoặc argon2id
- Không log password
- Không trả chi tiết lỗi cụ thể

---

## 11.2 CSRF Protection

Áp dụng:

- Web login form
- Session-based authentication

Laravel middleware:

```php
VerifyCsrfToken
```

---

## 11.3 Session Fixation Prevention

Sau login thành công:

```php
$request->session()->invalidate();
$request->session()->regenerateToken();
```

---

## 11.4 Rate Limiting

Laravel throttle middleware:

```php
ThrottleRequests:login
```

Policy:

| Rule         | Value  |
| ------------ | ------ |
| Max requests | 5      |
| Time window  | 1 phút |

---

## 11.5 Security Headers

```text

Secure
SameSite=Lax
X-Frame-Options: DENY
X-Content-Type-Options: nosniff
Content-Security-Policy
```

---

## 11.6 Audit Logging
